# Example data attribution

Wiz.io source is MIT; example data retain their separate licenses.

- **Oxygen workbook (Table S2)**: Christopher Balzer, Rama Oktavian, Mohammad Zandi, David Fairen-Jimenez and Peyman Z. Moghadam, *Wiz: A Web-Based Tool for Interactive Visualization of Big Data*, Patterns 1 (2020), 100107. https://doi.org/10.1016/j.patter.2020.100107 . The article and supplementary material carry **CC BY-NC-ND 4.0**: https://creativecommons.org/licenses/by-nc-nd/4.0/ . Distributed here as the unchanged published workbook; no commercial license is granted. It is separate from the restricted original Wiz code. Oxygen measurements originated from the MOF screening research cited by that article. The dynamic example is a replay, not new measurements.
- **S&P 500**: Ahmad Firdaus Cayzer, *sp500_data.csv*, Figshare, https://doi.org/10.6084/m9.figshare.26169322.v1 , **CC BY 4.0** https://creativecommons.org/licenses/by/4.0/ . Original CSV retained. A second CSV normalizes date strings for plotting. Historical index data, not live stock prices or the original company tickers.
- **Iris**: R. A. Fisher, UCI Machine Learning Repository, https://doi.org/10.24432/C56C76 , **CC BY 4.0**. Columns and labels renamed, row numbers added.
- **Wine**: S. Aeberhard and M. Forina, UCI Machine Learning Repository, https://doi.org/10.24432/C5PC7J , **CC BY 4.0**. Columns renamed/reordered, sample numbers added, cultivar IDs converted to 1/2/3.
- **Synthetic time series**: Wiz.io, MIT. Advanced example only.

See provenance.json for exact files, versions, transformations and SHA-256 checksums. All example files are hosted with the site; user files are never uploaded.
